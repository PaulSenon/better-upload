The demo runs the real client engine and server router in this tab, against an in-memory bucket and a simulated network.

## Install

```bash
npx shadcn@latest add https://<site>/r/upload.json
npx shadcn@latest add https://<site>/r/download-button.json
```

`upload` adds `components/upload/` (dropzone, item, list, resume banner, format helpers) and installs `@open-upload/react`,
`@open-upload/client`, `lucide-react`, plus the shadcn `button` and `progress` components. The files are yours to edit.

```tsx
import { useUpload } from '@open-upload/react';
import { UploadDropzone } from '@/components/upload/upload-dropzone';
import { UploadList } from '@/components/upload/upload-list';
import { UploadResumeBanner } from '@/components/upload/upload-resume-banner';

export function Uploader() {
  const upload = useUpload(client.videos);
  return (
    <div className="space-y-4">
      <UploadResumeBanner client={client} />
      <UploadDropzone control={upload.control({ input: { albumId: 'a1' } })} />
      <UploadList tasks={upload.tasks} />
    </div>
  );
}
```

| Component | |
|---|---|
| `UploadDropzone` | Drag and drop or click; accepts `control` from `useUpload`. Shows accepted types and limits from the contract. |
| `UploadItem` | Name, size, progress, a human status line and the actions that make sense now (pause, resume, retry, start over, select file, cancel). |
| `UploadList` | A list of `UploadItem`. |
| `UploadResumeBanner` | "You have an unfinished upload: select the file again". |
| `DownloadButton` | A stable download link for the browser's own download manager. |
