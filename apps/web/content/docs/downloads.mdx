---
title: Downloads
description: A stable, per-user link for the browser's own download manager.
icon: Download
---

```tsx
<a href={client.media.download.link({ input: { mediaId } })} download>Download</a>
```

The link points at your server. Each hit runs `onDownloadRequested` (with the user's session), then redirects to a
fresh presigned URL. So:

- **Retry always works**: the link never expires; a click or the browser's "retry" re-authorizes and re-signs.
- **Resume works while the presigned URL is valid**: browsers resume an interrupted download against the final URL.
  Size `expiresIn` to the expected download time (default 1 h, up to 7 days, capped by temporary credentials). After
  that, a retry restarts from zero — the download stays possible.
- **Access is checked on every hit**: revoking access in your app takes effect immediately.
- **No JavaScript needed**: it is a plain link (progressive enhancement).

`client.media.download.resolve({ input })` returns the presigned request and object info (size, ETag) for `<video src>`
or a custom downloader.

## Planned

- **Proxy mode on Cloudflare** (Worker + R2 binding): the stable link streams the bytes itself with `Range`, so resume
  works in every browser regardless of URL expiry. Zero egress on R2.
- **Managed downloads (v1)**: parallel ranged downloads into the best local sink (File System Access, OPFS), required
  for end-to-end encryption; falls back to the native link.
